
# embedded-spring-2027
embedded spring plan and project commit
此仓库是个人准备2027春招的计划与个人项目实现的说明
2027 春招嵌入式软件岗备战仓库：裸机 → RTOS → 通信协议 → 综合项目，全部产出可编译、可演示。
## 一、目标

### 总目标
2027 年 4 月前拿到嵌入式软件（MCU / 驱动方向）offer。

### 能力目标（可验证）

| 能力项 | 达标标准 | 验证方式 |
|---|---|---|
| 裸机开发 | 不依赖 HAL，用寄存器点亮 LED、配置 UART 收发、定时器 PWM | `01_bare_metal/` 下 8 个实验可编译烧录 |
| 中断与 DMA | 能说清 NVIC 优先级分组、DMA 传输完成/半完成中断的使用差异 | 实验 README 中的时序分析 + 面试口述 |
| RTOS | 能独立移植 FreeRTOS，说清优先级翻转与互斥量优先级继承 | `02_rtos/` 下 6 个机制实验 + 一篇原理笔记 |
| 通信协议 | 能不看代码写出 I2C / SPI / Modbus-RTU 的帧格式与时序 | `03_protocol/` 每协议一份协议说明 + 抓包图 |
| 工程能力 | 能独立完成 2 个可演示项目并写清难点与解法 | `04_projects/` 两个项目 + 演示 GIF |
| 职业准备 | 简历 1 页、项目讲解 5 分钟、常见八股 100 题过一遍 | `05_docs/` 内自查清单 |

### 产出目标
- [ ] 仓库 6 个目录全部有实质内容（非占位）
- [ ] 2 个可演示项目（接线 + 视频 + 源码）
- [ ] 简历上 3 条可量化的项目描述
- [ ] 一份 8 页以内的项目讲解稿

## 二、节奏

- **周期**：2026.10 – 2027.03，共 24 周
- **投入**：每周 20 小时（工作日 2h × 5 + 周末 10h）
- **固定动作**：
  - 周一 21:00 排本周任务，写进「每周清单」
  - 周三 21:00 中期检查，落后就砍任务而不是熬夜
  - 周日 21:00 复盘 + `git commit` + 勾选清单
- **原则**：宁可一周只完成 70%，也不要为了凑数留空目录。
